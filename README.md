# Purdy Electric — Website

Free homepage rebuild for Purdy Electric Co., Inc. (Rome, GA), built as a cold-outreach lead magnet.

**Live file:** [`index.html`](index.html) — a single self-contained file (CSS and all images inlined as base64), so it renders correctly no matter how it's opened: double-clicked, dragged into a browser, or sent as an email attachment.

**Dev source:** `dev.html`, `styles.css`, and `assets/` hold the editable, non-inlined originals for making future changes. After editing any of them, run `python build.py` to re-inline everything into `index.html` before sending.

## Known placeholders — not yet real

- Hero, About, and all four "Recent Work" gallery photos are temporary stock images (Pexels, free commercial license) — not real photos of Purdy Electric's team, trucks, or completed jobs. Each is credited with its source URL in an HTML comment in `dev.html`; the gallery photos are first in line to be replaced since a "Recent Work" grid is a stronger implied claim than a decorative hero shot.
- No confirmed public GA electrical contractor license number was found, so that stat tile was swapped for the business's confirmed Kohler/Cummins authorized-dealer status instead of guessing.
- No formal written guarantee exists on the business's own site, so the guarantee section is built from their own stated commitment plus a real customer quote, not an invented warranty.
